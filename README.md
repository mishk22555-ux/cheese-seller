# 🧀 Продавец сыра

Небольшой демонстрационный сайт магазина сыров, созданный для практики HTML, CSS и JavaScript.

На сайте представлены несколько видов сыра с описанием и отдельными страницами покупки.

## Возможности

- Просмотр доступных сыров
- Отдельная страница покупки для каждого товара
- Выбор количества товара с помощью кнопок `+` и `−`
- Ограничение минимального количества до `1`
- Плавная прокрутка по странице
- Hover-эффекты для кнопок и карточек
- Демонстрационный интерфейс оформления покупки

> Сайт является учебным проектом. Все товары, цены, контакты и заказы являются демонстрационными.

## Использованные технологии

- HTML5
- CSS3
- JavaScript
- Google Fonts
- WebStorm

## JavaScript

JavaScript используется для управления количеством товара на странице покупки.

Количество можно увеличивать без ограничения, а уменьшение ниже `1` запрещено.

## Запуск

Для запуска достаточно открыть `index.html` в браузере.

Также проект можно запустить через встроенный веб-сервер IDE, например WebStorm.

## Цель проекта

Проект создан для практики:

- семантической HTML-разметки;
- CSS Flexbox;
- BEM-именования классов;
- стилизации элементов;
- работы с DOM;
- обработки событий через `addEventListener`;
- изменения содержимого элементов через `textContent`.
